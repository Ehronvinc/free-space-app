# Garden of Thoughts

A small, private space for writing down random thoughts, unsaid feelings, rants, and anything else on your mind.

Garden of Thoughts is a browser-based notes app built with vanilla HTML, CSS, and JavaScript. It saves your notes directly in your browser using `localStorage`, so there is no account, server, or database involved.

## Features

- Create notes for any thought you want to write down
- Edit notes anytime
- Delete notes you no longer need
- Automatically saves changes in the browser
- Character counter with a 600-character limit per note
- Empty-state message when no notes exist
- Responsive layout for mobile, tablet, and desktop
- Soft note-card animations and randomly assigned card colors

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser `localStorage`

## How It Works

When you create or edit a note, the app saves your notes in your browser’s local storage. This means your notes stay available when you refresh or reopen the app.

> Your notes are stored only in the browser and device you used to write them. Clearing browser data or using another browser/device will remove or hide those notes.

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/Ehronvinc/free-space-app.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No installation or dependencies are needed.
